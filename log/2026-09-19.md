## 틀렸던 것

- **CV 를 안 열고 서지 DB 만 뒤졌다.** 소속을 Kim 그룹 단독으로 적고, 주소를 MIT 대표 주소로
  넣고, 참여 과제를 "데이터에 없다"고 보고했다. 셋 다 CV 1·5쪽에 있었다. user 지적.
  → memory `reference_cv_location_and_ownership` 등재.
- **기존 메모리를 어겼다.** Englund 표기 규칙이 이미 있었는데 CV 문구를 그대로 옮겼다.
  → 같은 메모리에 공개물 위계(Kim 먼저·단독, Englund 는 범위 한정) 추가.
- **공식 과제 제목을 임의로 줄였다.** MISTI 제목에서 `advanced quantum photonic integrated
  circuits` 를 잘랐고, 그게 Imperial 협업의 핵심이었다. 최종 보고서 기준으로 복원.
- **about 을 줄이자고 했다.** 중복만 보고 읽히는 자리를 안 봤다. user: 대부분 첫 화면만 본다.
- **CSS 명시도.** 번호 뱃지가 흰색으로 남은 것을 `!important` 만 붙여 두 번 놓쳤다.
- **빌드 확인.** `gh run watch` 종료 코드 0 인데 run 은 실패였고, 푸시 직후 `--limit 1` 로
  직전 빌드를 내 것으로 착각했다. 커밋 해시로 골라 기다리는 방식으로 바꿈.
