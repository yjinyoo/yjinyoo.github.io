simulation runs

Every run counted in the activity calendar on the front page.

11,677 finished runs since July 2025, one row each. A run is counted once it finished: a cloud job that returned its result, or a cluster job that completed and ran for more than a minute. Drafts, failed jobs and runs on local machines are not listed.

The id is the first eight hex digits of the cloud task id, or the cluster job id, so any row can be matched against the provider’s records on request. Task names are withheld because they carry design parameters of unpublished work. Rows dated by month only come from the first archive, in 2025, which kept the month and not the day.
